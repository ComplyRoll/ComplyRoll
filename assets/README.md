# Brand assets

| File | Use |
|---|---|
| `complyroll-avatar-1024.png` | GitHub organization and repository avatar (full-bleed square; GitHub applies its own corner radius) |
| `complyroll-avatar-512.png` | Same mark, smaller upload |
| `complyroll-banner.png` | README banner, 2400x640 (renders at 1200 CSS px) |
| `complyroll-banner-1200.png` | README banner at 1x |
| `complyroll-mark-512.png` / `-256.png` / `-64.png` | Standalone mark with rounded corners and transparent background; the 64px file is the inline bullet size |
| `*.svg` | Editable sources for every raster above |

The mark is a response clock closing over three tracked records. The ink arc is the window already
spent, the accent arc is what is left, and the accent row is the finding whose clock is running.

## Tokens

| Token | Value | Role |
|---|---|---|
| Ground | `#0B1220` | Icon and banner background, base of the gradient |
| Ground (lift) | `#111C31` | Gradient partner, top-left |
| Ink | `#E9EDF2` | Mark body, wordmark |
| Muted | `#8A97A8` | Secondary type |
| Accent | `#E8B14C` | Compiled row, kicker, rules |
| Warn | `#E8B14C` | Response window closing |
| Alert | `#E2603C` | Overdue |

Wordmark is JetBrains Mono 800 at 15 units of letter-spacing. The strip under the wordmark is a
response-clock burn-down: bars hang from the rule, shortest are the overdue ones.
